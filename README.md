🌤️ Simple Weather App [https://wederwebapp.vercel.app/]

A simple weather app built with Next.js that shows:

Hourly and daily weather forecast

Auto-suggest search bar for locations

Dark/Light mode toggle

🚀 Features

Hourly & Daily Forecast – View detailed weather for each hour and day.

Auto-suggest Search – Quickly search for any city.

Dark Mode – Toggle between light and dark themes.

Responsive UI – Works on mobile and desktop.

Weather Icons – Dynamic icons based on precipitation and weather codes.

🛠️ Tech Stack

Next.js 13
– React framework for server-side rendering

TypeScript
– Type-safe JavaScript

React Context API
– State management

Tailwind CSS
– Utility-first CSS framework

Lucide Icons
– Weather icons
